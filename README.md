## 📌 About the Project

**AI Career & College Assistant** is an AI-powered chatbot developed by **Karan Negi 👽🤷‍♂️** to help students with career guidance, college-related questions, general AI conversations, and document-based question answering.

The application combines **Google Gemini** with **Retrieval-Augmented Generation (RAG)** to provide intelligent and context-aware responses.

Users can upload college or educational PDF documents 📚 and ask questions based on their content. The application processes the documents, creates semantic embeddings, searches for relevant information using **FAISS**, and uses **Google Gemini** to generate the final response.

### 🎯 Main Goal

The main goal of this project is to create a **student-friendly AI assistant** that combines modern Generative AI and RAG technology into one practical application.
